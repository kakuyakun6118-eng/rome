# 会戦のイメージ画の追加方法

このフォルダに画像を置き、`src/ui/battleArt.json` に登録すると、
戦闘画面の上に帯として出る。**1枚も置かなければ帯ごと出ない**ので、
少しずつ足していける。肖像（`../portraits/`）と同じ考え方。

## 画像の仕様

| 項目 | 値 |
|---|---|
| 寸法 | **横長**。比率 341:133（約 2.56:1） |
| 形式 | WebP（品質 80〜85 目安） |
| 1枚あたり | 40 KB 以内が望ましい |
| 題字 | **焼き込まない**（UI側で下に添えるため） |

帯として出すので縦は取らない。戦闘画面の主役は下の布陣図のほうで、
画は「いまどんな戦いをしているか」を一目で示すためだけに置く。

## 構図

- 会戦の**群像**。中景に指揮官、周囲に兵。顔の見分けは要らない
- 地形が読めること（森・丘・砂漠・河・城壁）。**選ばれる条件が地形**なので、
  ここが曖昧だと画と戦場が食い違う
- 光の向きと色温度を全カットで揃える

## 登録

`src/ui/battleArt.json` の `entries` に並べる。

```json
{
  "file": "adrianople.webp",
  "title": "アドリアノープルの戦い（378年）",
  "terrain": ["plain", "hill"],
  "foe": ["barbarian"]
}
```

| 項目 | 意味 |
|---|---|
| `terrain` | `plain` / `hill` / `forest` / `desert` / `river` から複数 |
| `foe` | `barbarian` / `east` / `persia` から複数 |
| `capital` | `true` なら都での戦い専用（攻城戦の画）。地形と相手は見ない |

## 選ばれ方

戦場から決定的に1枚を選ぶ。**同じ戦場なら激突を重ねても画は変わらず**、
セーブして読み直しても変わらない。

都（イタリア・トラキア）での会戦は `capital: true` の画から選ぶ。
それ以外は次の順で条件を緩める。

1. 相手と地形が一致
2. **地形だけ一致**
3. 相手だけ一致

地形を相手より先に残しているのは、この大きさの帯では画の見た目を
決めるのが地形のほうだからで、砂漠の会戦にガリアの平原の画が出るほうが、
そこに写る兵の民が違うことより目につく。
