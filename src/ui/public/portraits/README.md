# 肖像画像の追加方法

このフォルダに画像を置き、`src/ui/portraits.json` に登録すると、
君主・皇后の肖像が SVG から画像に切り替わる。
**1枚も置かなければ従来どおり SVG の肖像が使われる**ので、少しずつ足していける。

## 画像の仕様

| 項目 | 値 |
|---|---|
| 寸法 | **640 × 832 px**（縦長・比率 100:130） |
| 形式 | WebP（品質 80〜85 目安） |
| 1枚あたり | 60〜120 KB 以内が望ましい |
| 背景 | 塗りつぶし（透過にしない） |
| 額縁 | **付けない**（UI側で金の枠を付けるため） |

寸法は SVG 肖像の縦横比と同じにしてある。画像が無いときに SVG へ落ちても
レイアウトがずれない。640・832 はいずれも 64 の倍数なので画像生成モデルにも扱いやすい。

## 構図

肖像を並べたときに揃って見えることが、1枚ごとの完成度より重要になる。

- **胸像**（頭と肩まで）。正面またはごく浅い斜め
- 目線の高さを**上から約 38%** の位置に揃える
- 頭頂の上に冠を含めて 8〜12% の余白
- 光の向き・色温度・背景の明るさを全カットで統一する
- 顔が中央に来るようにする（UIでは 80px 幅で表示されるため、小さくても顔が判別できること）

## ファイル名

```
{role}_{origin}_{age}_{variant}.webp
```

| 部分 | 取りうる値 | 意味 |
|---|---|---|
| `role` | `emperor` / `consort` | 皇帝か皇后か |
| `origin` | `roman` / `east` / `barbarian` | 出自（皇后に `roman` は無い） |
| `age` | `youth` / `adult` / `elder` | 19歳以下 / 20〜49歳 / 50歳以上 |
| `variant` | `01`, `02`, … | 同じ属性の中の差し替え候補 |

例:

```
emperor_roman_adult_01.webp
emperor_roman_elder_02.webp
emperor_barbarian_youth_01.webp
consort_east_adult_01.webp
consort_barbarian_adult_03.webp
```

**髪色や肌の色はファイル名に含めない。** 同じ属性の中の差異は `variant` で吸収する。
そうしないと組み合わせが際限なく増える。

皇后は年齢を持たないデータなので `adult` に固定してよい。

## 推奨する枚数

| 役割 | 出自 | 年代 | variant | 小計 |
|---|---|---|---|---|
| emperor | 3 | 3 | 3 | 27 |
| consort | 2 | 1 | 3 | 6 |
| | | | **合計** | **33** |

640×832 の WebP なら合計 3〜4 MB 程度。遅延読み込みするので初回表示は妨げない。

まず `emperor_roman_adult` と `consort_east_adult` だけ作って動かし、
足りない属性は自動で近いものに置き換わる（下記）ので、後から足していける。

## 登録

`src/ui/portraits.json` の `entries` に並べる。

```json
{
  "version": 1,
  "basePath": "/portraits/",
  "entries": [
    { "file": "emperor_roman_adult_01.webp", "role": "emperor", "origin": "roman", "age": "adult" },
    { "file": "emperor_roman_adult_02.webp", "role": "emperor", "origin": "roman", "age": "adult" },
    { "file": "consort_east_adult_01.webp", "role": "consort", "origin": "east", "age": "adult" }
  ]
}
```

ファイル名は規約どおりでなくても `entries` の属性が正しければ動くが、
名前と属性を一致させておくほうが管理しやすい。

## 割り当ての規則

人物の `id` から決定的に1枚を選ぶ。**同じ皇帝は常に同じ肖像**になり、
セーブして読み直しても変わらない。代替わりすれば別の肖像になる。

属性が完全に一致する画像が無い場合は、次の順で条件を緩める。

1. 出自と年代が一致
2. 出自だけ一致
3. 年代だけ一致
4. 役割だけ一致
5. どれも無ければ SVG の肖像

## 生成時のコツ

同じ文面の「構図・照明・背景」部分を全カットで固定し、
人物の記述だけを差し替えると揃いやすい。

- 共通部分の例: 「胸像、正面、柔らかい斜光、暗い大理石の壁龕を背景、
  金の刺繍が入った帝室紫の衣、写実的な油彩、640×832」
- 差し替える部分: 年代（青年／壮年／老年）、出自（ローマ／東方／ゲルマン）、
  髪色、髭の有無、宝冠の意匠

`variant` 違いは同じ文面のままシード値だけ変えるとばらけすぎない。
