# 戦場の地の画の追加方法

このフォルダに画像を置き、`src/ui/terrainArt.json` に登録すると、
戦闘画面の布陣図の地がその画に差し替わる。
**1枚も置かなければ従来どおり線と面で描いた地形**が使われるので、
1地形ずつ足していける。肖像（`../portraits/`）や会戦のイメージ画
（`../battles/`）と同じ考え方。

現在は5枚とも `scripts/generate-terrain.py` の出力を登録してある。
より良い画が用意できたら**同じファイル名で置き換えるだけ**でよい。

## いちばん大事なこと

**兵を描き込まない。** 地形だけを描く。

兵はゲームの状態から描いている。背景に焼き込むと、兵数が変わっても
駒が動かず、隊が崩れても消えず、迂回しても向きが変わらない。
「絵に見える」ようになるかわりに、布陣図として読めなくなる。

同じ理由で、**旗・陣幕・馬防柵・矢の飛跡なども入れない。**
地形と、動かない地物（岩・木・川・畦道・城壁）だけにする。

## 画像の仕様

| 項目 | 値 |
|---|---|
| 寸法 | **960 × 894 px**（比率 320:298。布陣図の viewBox と同じ） |
| 形式 | WebP（品質 80〜85 目安） |
| 1枚あたり | 120 KB 以内が望ましい |
| 視点 | やや高い位置からの俯瞰。地平線は**入れない**（空を映さない） |
| 光 | 左上から。全5枚で向きと色温度を揃える |

比率を布陣図と同じにしてあるので、`xMidYMid slice` で敷いても
どこも切り落とされない。

## 構図

画面は上下に3つの帯として読まれる。

| 帯 | 位置 | 何が乗るか |
|---|---|---|
| 上（奥） | 上から約 1/4 | 敵の隊と兵数の札 |
| 中（戦場） | 中央 約 1/2 | 命令の矢が横切る |
| 下（手前） | 下から約 1/4 | ローマ軍の隊と兵数の札 |

- **上下の帯は簡素に。** ここに岩や木を密に置くと、その上に乗る
  兵と札が読めなくなる。UI 側でも上下だけ薄く落としているが、
  画の側でも空けておくほうが良い
- **中央に見せ場を置く。** 尾根・川・林の切れ目・畦道など、
  「どこを越えて攻めるか」が読める地物を中央の帯に置く
- 手前ほど大きく粗く、奥ほど小さく霞ませる

## 5枚の内訳

| ファイル | 地形 | 出る属州 |
|---|---|---|
| `plain.webp` | 平原 | ガリア・トラキア |
| `hill.webp` | 丘陵 | ヒスパニア・イタリア・イリュリクム・アシア |
| `forest.webp` | 森林 | ブリタンニア |
| `desert.webp` | 砂漠 | アフリカ・オリエンス・エジプト |
| `river.webp` | 渡河点 | ノリクム（ドナウ河畔） |

## 生成するときの文面

共通部分を固定し、地形の記述だけ差し替えると5枚が揃う。

> 共通: 「5世紀ローマの戦場を高所から見下ろした俯瞰図。
> **人物・兵士・馬・旗・天幕は一切描かない。** 空と地平線を入れず、
> 地面だけで画面を満たす。左上からの午後の斜光。落ち着いた土色の油彩。
> 画面上端と下端の帯は開けた平地にして、中央に地形の見せ場を置く。
> 960×894」
>
> - 平原: 「収穫前の麦畑と草地。畦道が横切る。点在する低木」
> - 丘陵: 「連なるなだらかな丘。稜線に陽が当たり、その下に陰が落ちる。露岩と灌木」
> - 森林: 「深い針葉樹林。中央に開けた林間の空き地。倒木と下草」
> - 砂漠: 「乾いた砂丘と礫の平地。稜線に陽、風下側に陰。乾いた低木」
> - 渡河点: 「浅い川が画面を横切る。石の多い河原と浅瀬。両岸は草地」

## 手続き的な仮の地

絵が用意できるまでの繋ぎとして、標高場に陰影を付けて色を乗せた
画を書き出すスクリプトがある（numpy と Pillow が要る）。

```
python3 scripts/generate-terrain.py
```

**写実的に描かれた戦場画の代わりにはならない。** 標高場に陰影を付けた
「地図に近い地」で、絵として描かれたものとは別物。それでも布陣図の
下敷きとしては読めるので、5枚とも登録してある。

作るときに踏んだ罠を残しておく。どれも一度は実際に起きた。

| やったこと | どう見えたか |
|---|---|
| ノイズを6段重ねる | 細かい皺が全面に立ち、丘陵も砂漠も「くしゃくしゃの紙」になった |
| 1px の線を数万本引いて畝を作る | 縦線が並んで画面全体に網目が浮いた。面として作って乗せるべき |
| 標高場を8bitに丸めてからぼかす | なだらかな面に段差ができ、陰影が等高線として拾った。浮動小数のままぼかす |
| 砂丘を縦の転がし平均で均す | 縞模様の筋が全面に出た。格子の縦横比で向きを付けるべき |
| 森の地面を暗いまま置く | 上に重なる紺の隊が地面に沈んで読めなくなった |
| 倒木を明るい茶で置く | 赤い棒が散らばっているように見えた |

正弦波の合成（`np.sin` / `np.cos` を足し合わせる）でも試したが、
ぼやけた縞模様にしかならず地形には見えなかった。標高場・陰影・
植生を積むところまでやって、ようやく地面として読める。

## 登録

`src/ui/terrainArt.json` の `entries` に並べる。

```json
{
  "version": 1,
  "basePath": "/terrain/",
  "entries": [
    { "terrain": "forest", "file": "forest.webp" },
    { "terrain": "hill", "file": "hill.webp" }
  ]
}
```

`terrain` は `plain` / `hill` / `forest` / `desert` / `river` のいずれか。
登録が無い地形、および**読み込みに失敗した画**は、線と面で描いた
地形にそのまま落ちる（SVG の `<image>` は失敗しても穴が開くだけで
気付けないので、先に読み込んでから差し替えている）。
