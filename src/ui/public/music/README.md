# 背景音楽

**既定では音源ファイルを使わない。** 古代ローマ風の譜面を Web Audio で
その場で合成している（`src/ui/romanScore.ts`）。このフォルダが空でも音は鳴る。

外部フォントを読み込まず雷紋も CSS で描くのと同じ方針で、
配信サイズを増やさずに音を付けている。権利の問題も起きない。

## 手持ちの曲に差し替える

このフォルダに **`theme.mp3`** を置くと、合成した譜面よりそちらが優先される。

```
src/ui/public/music/theme.mp3
```

| 項目 | 値 |
|---|---|
| ファイル名 | `theme.mp3`（固定） |
| 形式 | MP3（Safari・Chrome・Firefox のいずれでも再生できる） |
| 長さ | 2〜5分程度。末尾から先頭へ繰り返し再生される |
| 音量 | コード側で 0.4 に落としている（`music.ts` の `DEFAULT_VOLUME`） |

繰り返し再生されるので、**曲の終わりと始まりがつながる音源**のほうがよい。

**音源はこのリポジトリに含めない。** 市販曲は権利者の許諾なしに同梱・配布できない。
`.gitignore` で `*.mp3` を除外してあるので、置いても誤ってコミットされない。

## 再生の挙動

- ブラウザは操作なしの自動再生を許さないため、**難易度を選んだ時点**で鳴り始める
- 画面右上のボタンでいつでも止められる。選択は `localStorage` に残るので、
  一度止めれば次回以降も止まったままになる

## 合成している譜面について

ローマの音楽はほとんど現存しないので、当時の音楽論と楽器から組んでいる。

| 要素 | 中身 |
|---|---|
| 旋法 | ドリア旋法（D）。長調・短調の機能和声を使わず、終止形を作らない |
| ドローン | 主音と5度を鳴らし続ける。和音は動かさない |
| 旋律 | アウロス（複簧の管楽器）を模した音色。鋸歯波を共振の強い低域通過で削る |
| 伴奏 | リュラ（竪琴）の分散和音。三角波の短い減衰 |
| 打楽器 | ティンパヌム。音程の落ちる低い打音を行進の脈として置く |
| 残響 | 石造の広間。指数減衰の雑音から畳み込み用の応答を作る |
| 速度 | 66 BPM。速くすると軍楽になり荘重さが消える |

旋律は3つの句（A・B・C）を `A A B A C B A A` の順で繰り返す。
1周およそ1分。句の並びと音色は `romanScore.ts` の定数を変えれば調整できる。
